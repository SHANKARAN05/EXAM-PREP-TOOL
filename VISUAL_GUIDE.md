## 🎬 User Journey

```
New User
   │
   ├─→ Visits Home Page
   │      │
   │      ├─→ Sees 3 Subject Cards + Combined Exam
   │      │
   │      └─→ Chooses Study Mode (Java)
   │             │
   │             ├─→ Reviews Questions with Answers
   │             ├─→ Uses Filters (Topic, Type)
   │             ├─→ Searches for Keywords
   │             └─→ Marks Questions as Reviewed
   │
   ├─→ Ready for Exam
   │      │
   │      ├─→ Chooses Exam Mode (Java)
   │      │      │
   │      │      ├─→ Enters Name
   │      │      ├─→ Selects 10 Questions
   │      │      ├─→ Starts Exam
   │      │      ├─→ Answers Questions
   │      │      ├─→ Navigates with Prev/Next
   │      │      └─→ Submits Exam
   │      │
   │      └─→ Views Result
   │             │
   │             ├─→ Sees Score (8/10 = 80%)
   │             ├─→ Reviews Wrong Answers
   │             └─→ Understands Mistakes
   │
   └─→ Advanced Practice
          │
          └─→ Takes Combined Exam
                 │
                 ├─→ 30 Questions (All Subjects)
                 ├─→ Completes in 30 Minutes
                 ├─→ Views Subject-wise Breakdown
                 └─→ Identifies Weak Areas
```
